# Part 1 Evidence — Screenshot Guide

## Instructions

Save your dated screenshots here following the naming convention below.
Each screenshot should have the date/time visible (use Windows Snipping Tool which timestamps automatically).

## Required Screenshots

| File Name | Step | What to Capture |
|-----------|------|-----------------|
| `step1_environment_access.png` | Step 1 | The `sales.polluxa.com` landing page |
| `step2_signup_dashboard.png` | Step 2 | Dashboard with left sidebar showing "Integration" |
| `step3_connect_linkedin.png` | Step 3 | LinkedIn tab with "+ Connect LinkedIn Account" button |
| `step4_credential_modal.png` | Step 4 | The authentication modal (blur your password) |
| `step5_account_age_tier.png` | Step 5 | Account Age selection screen |
| `step6_agent_running.png` | Step 6 | Leads list and/or agent activity results |

## Additional Notes File

Create a file called `notes.txt` in this directory with:
1. The Account Age tier you selected
2. Any challenges or failures encountered during the handshake
3. Date and time of completion

## Example `notes.txt`

```
Account Age Tier Selected: 1+ Year
Daily Invite Limit: 30
Daily Message Limit: 60
Risk Classification: Minimal Risk

Challenges:
- None encountered. MFA approval on phone was instant.

Completed: 2026-08-19 22:00 IST
```
